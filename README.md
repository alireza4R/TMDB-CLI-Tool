# TMDB API Client
- This is a solution for the TMDB CLI Tool project on https://roadmap.sh/projects/tmdb-cli
- A Java console application that interacts with The Movie Database (TMDB) API to fetch and display movie information.

## Prerequisites

- Java 21 or higher recommended
- API token from themoviedb

## Setup and Run

To use this application, you must provide your own TMDB API Token.

1. Go to [The Movie Database (TMDB)](https://www.themoviedb.org/) and sign up for a free account.
2. Navigate to your Account Settings > API.
3. copy your **API Access Token**.
4. Run the application's `Main` class.
5. When the terminal prompts you, paste your API token.
6. Use the numeric menu to fetch and view movie lists.
